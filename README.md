# Sillytavern-Per-Character-BG
Haven't seen any extension where you can select a background and lock it to a single character. So here we are.

<img width="1470" height="949" alt="Screenshot 2026-10-19 142237" src="https://github.com/user-attachments/assets/8310d64d-8e02-4b58-88cf-2c8f90c5a637" />


Nested in the native background settings in Sillytavern. Very straight forward to use. You can add, change or replace the image you select, which will make it fall back to the global background.

You can still upload your own custom background from outside of Sillytavern, that option is there as well.

**Latest update:** you can now add images straight from the Sillytavern gallery. If the character has images in their gallery, hit "Choose from Gallery", pick one from the thumbnails and that's your background. Still tied to that one character, not the chat and not global.

**Previous update:** each background also has a Blur slider (0-20px) and a Darkness slider (0-100%), saved per character.

That's literally it.
