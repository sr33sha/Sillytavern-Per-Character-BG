# Sillytavern-Per-Character-BG
Haven't seen any extension where you can select a background and lock it to a single character. So here we are.

<img width="1099" height="1023" alt="Screenshot 2026-11-09 115154" src="https://github.com/user-attachments/assets/d7edcae5-be03-474e-9135-7e2ce3ba4e22" />

Nested in the native background settings in Sillytavern. Very straight forward to use. You can add, change or replace the image you select, which will make it fall back to the global background.

You can still upload your own custom background from outside of Sillytavern, that option is there as well.

**Latest update:** you can now use colors as a background too. Hit "Apply Color" and pick a soft gradient (two colors and an angle) or a solid color, with a live preview before you apply it. The Darkness slider works on colors as well. Still tied to that one character, not the chat and not global.

**Previous updates:**
- You can add images straight from the Sillytavern gallery. If the character has images in their gallery, hit "Choose from Gallery", pick one from the thumbnails and that's your background.
- Each background also has a Blur slider (0-20px) and a Darkness slider (0-100%), saved per character.

That's literally it.
